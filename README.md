# Rainbow Deskmates

把本机的 Codex 和 DeepSeek Harness (DSH) 放进同一个桌面会话。每个角色有自己的名字、角色标签、性格和形象。

## 启动

macOS 应用包可以放进「应用程序」，通过 Spotlight 搜索 **Rainbow Deskmates** 打开。应用调用本机已安装并完成登录的 Codex 和 DSH。

从源码启动或打包需要 Node.js 22.12 或更新版本。

```sh
npm ci
npm start
```

第一次安装和运行时，Electron 会下载相应平台的桌面运行时。应用没有独立的账号。进入「运行时设置」可以检查识别结果和指定可执行文件。macOS 会优先查找 ChatGPT 桌面应用附带的 Codex，然后查找 PATH 中的 CLI。

在 macOS 上运行 `npm run package:mac`，可生成可双击启动的 `.app`。输出路径会打印在终端。

## 使用

- 「角色」可设置名称、业务标签、性格、模型和推理强度，或在独立的立绘与 Q 版之间切换。使用前请为每个角色从运行时列表选择模型。模型提供推理档位时也需要选择档位。成员卡显示当前选择，新回复会记录本轮的模型和推理强度。
- 从角色库选择要加入会话的成员，并可为会话指定本地工作目录。点击消息上的回复按钮可在当前聊天引用该消息。
- 会话右上角可以展开「会话设置」，修改名称、详情、工作目录、写权限和交接开关。会话详情在首次打开或有变更时提供给成员。
- 右键会话或回复线程，可重命名或删除。删除会话时，其消息和下属回复线程会一并删除。
- 在「运行时设置 → 自动分流」单独选择分流模型和推理强度。未点名的消息会保存后分流，可保持安静、请一位成员回复、延续已有任务或拆成多项工作。用 `@成员全名` 可以直接点名。回复期间可以继续发消息或停止当前会话的工作。
- 独立任务由不同成员并行处理，前置工作完成后才会启动依赖任务。同一成员一次处理一轮。同一项目的写操作依次执行。任务卡显示负责人和状态，点击「追问」会把追加要求送到该任务的会话。
- 在消息上用「指定成员接手」交接。新会话默认允许 Agent 直接交接，每轮最多追加两次交接，成员在同一项工作内至多接手一次。
- Agent 可在工作过程中增删会话笔记，记录关键决定和进度。笔记按会话保存为 Markdown，设置栏中可以按文件打开或删除。新开的运行时会话会读取近期笔记，续聊会收到笔记变更。交接时可在说明中写出笔记文件名，应用会优先提供相关内容。
- 工作目录默认只读。选择本地目录后可针对该会话开启写权限。

程序和聊天记录都在本机。运行时会使用各自已配置的模型服务，共享消息上下文会作为输入发给这些服务。Rainbow Deskmates 的聊天、配置和运行时会话映射保存在 Electron 用户数据目录的 `workspace.json`，macOS 默认位于 `~/Library/Application Support/Rainbow Deskmates/`。

## 实现

Electron 主进程负责本地持久化、队列和运行时。Codex 使用 `exec --json` 和 `exec resume`，复用已有认证，采用本应用的会话权限配置。DSH 使用 `--profile headless --json` 和 `--session-id`。运行时会话按共享会话和角色分别保存，应用将对话上下文交给被唤醒的角色。

```sh
npm test
npm run build
```

协作功能参考了 [Raft](https://raft.build/zh-cn/) 的成员、私有收件目标、回复线程和交接设计。界面和实现为 Rainbow Deskmates 独立制作。

角色素材来源及使用说明见 [素材署名](./public/art/NOTICE.md)。
