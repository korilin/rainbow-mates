# Rainbow Mates

把本机的 Codex 和 DeepSeek Harness (DSH) 放进同一个桌面会话。每个角色有自己的名字、角色标签、性格和形象。

## 启动

macOS 应用包可以放进「应用程序」，通过 Spotlight 搜索 **Rainbow Mates** 打开。应用调用本机已安装并完成登录的 Codex 和 DSH。

从源码启动或打包需要 Node.js 22.12 或更新版本。在 macOS 上构建 Computer Use 还需要 Xcode 命令行工具。

```sh
npm ci
npm start
```

第一次安装和运行时，Electron 会下载相应平台的桌面运行时。应用没有独立的账号。进入「运行时设置」可以检查识别结果和指定可执行文件。macOS 会优先查找 ChatGPT 桌面应用附带的 Codex，然后查找 PATH 中的 CLI。

在 macOS 上运行 `npm run package:mac`，可生成可双击启动的 `.app`。输出路径会打印在终端。

## 版本号

应用显示 `大版本.业务版本.小版本.包版本`，例如 `0.1.0.007`。前三段来自 `package.json` 的 `version`，在明确要求升级时修改。大版本仅用于重大重构或业务变动。业务版本用于功能发布，小版本用于该版本内的修复和小功能。

每组前三段的首包使用 `000`，此后每次打包自动加一，直到 `999`。到上限后需要指定新的发布版本。本机的打包记录保存在 `~/Library/Application Support/Rainbow Mates Build/versions.json`，清理 `.release` 后仍会继续编号。使用 `npm start` 启动源码会显示「开发」，并沿用已配置的前三段。

## 使用

- 右上角「设置」可切换浅色和深色主题，选择后立即生效并保存在本机。
- 「设置 → 个人资料」可以更改你的显示名和头像，聊天记录与消息引用会使用当前显示名。
- 「角色」可设置名称、业务标签、性格、模型和推理强度，或在独立的立绘与 Q 版之间切换。使用前请为每个角色从运行时列表选择模型。模型提供推理档位时也需要选择档位。成员卡显示当前选择，新回复会记录本轮的模型和推理强度。
- 从角色库选择要加入会话的成员，并可为会话指定本地工作目录。点击消息上的回复按钮可在当前聊天引用该消息。
- 点击会话标题下方的成员头像可切换聊天左侧的成员列表，右上角的按钮独立展开右侧内容。拖动聊天与右侧内容之间的分隔线可以调整宽度。右键会话打开「会话设置」，可以修改名称、详情、工作目录、写权限和交接开关。会话详情在首次打开或有变更时提供给成员。
- 新建会话进入默认分组。可以新建自定义分组并拖动会话跨组移动。组内按最近活跃时间排序，回复线程随所属会话移动。
- 右键会话或回复线程，可重命名、复制会话 ID、导出 JSON 或删除。导出包含消息、成员、任务、笔记和下属回复线程。删除会话时，其消息和下属回复线程会一并删除。
- 用户消息进入各成员的聊天队列。用 `@成员全名` 或「让成员名做某事」可以指定回复对象，其他成员仍会收到消息作为聊天上下文。输入 `@` 可选择成员、其他会话、Skill、Plugin、文件和目录。输入 `$` 或 `/` 可选择 Skill 或 Plugin，并浏览 Plugin 下的 Skill。上下键切换选项，回车确认，Esc 关闭列表并保留输入。Skill、Plugin 和会话引用直接显示在正文里。
- 点击成员卡，或点角色回复下方的「查看任务线程」，可查看该成员的任务指令、补充要求、工具进度和执行结果。网页、笔记、文件改动和回复附件按打开的内容分别显示在标签页。
- 右侧首个标签页固定为工作目录。文件可以打开预览，文件和目录都可以右键引用、拖入聊天，或从 Finder 拖入和粘贴。引用卡片显示在输入框上方，图片会显示缩略图。
- 成员卡显示未连接、回复中、任务中或空闲。成员在独立的任务线程开展工作，执行期间仍能接话。同一项目的写操作依次执行。任务卡显示负责人和状态，点「追问」可补充要求。成员会从聊天把任务改动转给任务线程。
- 在消息上用「指定成员接手」交接。交付先到接手成员的聊天线程，由它结合已有产出决定直接回复或继续任务。续办沿用已交付的结论，追加尚需核对的事项。新会话默认允许 Agent 直接交接，每轮最多追加两次交接，成员在同一项工作内至多接手一次。
- Agent 可在工作过程中增删会话笔记，记录关键决定和进度。笔记按会话保存为 Markdown，在内容详情的「笔记」中可以打开或删除。新开的运行时会话会读取近期笔记，续聊会收到笔记变更。交接时可在说明中写出笔记文件名，应用会优先提供相关内容。
- 工作目录默认只读。选择本地目录后可针对该会话开启写权限。
- 在 macOS 上，可在「会话设置」勾选「允许 Computer Use」并保存。辅助功能权限用于读取和操作界面，屏幕录制权限用于截图。界面文字和截图可能作为输入发送给成员使用的模型。

程序和聊天记录都在本机。运行时会使用各自已配置的模型服务，共享消息上下文会作为输入发给这些服务。Rainbow Mates 的聊天、配置和运行时会话映射保存在 Electron 用户数据目录的 `workspace.json`，新安装在 macOS 上默认使用 `~/Library/Application Support/Rainbow Mates/`。旧版升级会继续使用已有的数据目录。

## 实现

Electron 主进程负责本地持久化、队列和运行时。Codex 通过本机 `app-server` 创建、续用和更新线程。DSH 通过 `headless` 续用会话，任务运行时在下一个步骤接收追加要求。若当前轮已经无法接收，应用会在同一任务里续跑。每位成员在各共享会话里分别保存聊天与任务的运行时线程。

启用 Computer Use 的成员在执行期间通过本机 MCP 调用 macOS 桌面工具。成员可以通过辅助功能读取控件和文字，模型支持图片输入时也可以使用截图。

```sh
npm test
npm run build
```

协作功能参考了 [Raft](https://raft.build/zh-cn/) 的成员、私有收件目标、回复线程和交接设计。界面和实现为 Rainbow Mates 独立制作。

角色素材来源及使用说明见 [素材署名](./public/art/NOTICE.md)。
